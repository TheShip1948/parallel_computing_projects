# MP8: Sparse Matrix-Vector Multiplication (SpMV)

## Objective
The objective of this task is to implement and compare performance for Sparse Matrix-Vector Multiplication (SpMV) using CSR (Compressed Sparse Row) and JDS (Jagged Diagonal Storage) formats. The goal is to demonstrate how data layout optimizations, such as Jagged Diagonal Storage, can improve memory coalescing and performance for irregular data structures.
