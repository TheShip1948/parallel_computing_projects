Step 1 inside forward(): im2col via convolve_valid()

The utility in Utils/Convolution.h extracts every valid 3×3 patch from the input and lays each patch as one column of a new matrix m_col.

For a 5×5 input with a 3×3 filter (stride 1, valid padding) there are 3×3 = 9 output positions, so m_col has 9 columns per sample.

m_col shape: (in_ch × fh × fw) × (out_h × out_w × n_obs)
= 9 × 9

Step 2: matrix multiply m_z = m_weight × m_col

m_weight stores all filters. Each row is one output channel's filter, flattened to a row vector.

m_weight shape: out_channels × (in_ch × fh × fw) = 1 × 9
m_weight (1 × 9) — cross filter
Result: m_z (before bias) = m_weight × m_col
shape: out_channels × (out_h × out_w × n_obs) = 1 × 9
each value = dot(filter row, m_col column) = one convolution output pixel
How one output pixel is computed

This is equivalent to m_weight.row(0) · m_col.col(0) — the matmul computes all 9 positions at once, making convolution a single BLAS call.

Step 3: bias addition

m_bias has shape out_channels × 1 = 1 × 1. It is broadcast across all output positions and all samples.

The Eigen code is equivalent to:

m_z.colwise() += m_bias

Step 4: activation Activation::activate(m_z, m_a)

The template parameter Activation (here: ReLU) applies element-wise. The result is stored in m_a — the layer's output, passed to the next layer.

ReLU: f(x) = max(0, x). Any value ≤ 0 is clamped to 0.

m_a shape = m_z shape = out_channels × (out_h × out_w × n_obs)
= 1 × 9

The 9 values of m_a represent the single output channel, reshaped back to 3×3. Darker = larger activation.
