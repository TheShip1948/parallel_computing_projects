# MNIST Inference Tutorial (test4)

This tutorial demonstrates how to load a pre-trained neural network and perform inference (prediction) using the MiniDNN library.

## Objective
- Load a pre-trained model from the `NetFolder` (generated by `test3`).
- Load the MNIST test dataset.
- Select the first **5 images** from the test set.
- Pass the images through the network to get predictions.
- Compare the predicted digit with the actual label and report the results.

## Requirements
- This tutorial requires the `NetFolder/` directory to contain valid model weights (produced by running `test3` first).

## How to Build and Run
On Windows (with CUDA/NVCC installed):
1. Run `build.bat`.
2. The executable will be created in `build/test4.exe`.
3. The program will display the prediction results for 5 images in the console.

## Output Example
```text

  Actual Number:    7
  Predicted Number: 7
  Result:           TRUE

...
```
